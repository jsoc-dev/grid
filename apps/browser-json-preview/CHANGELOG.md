# browser-json-preview

## 0.0.1

### Patch Changes

- Initial release: Previews JSON documents and API responses as interactive tables, powered by JSOC Grid and TanStack Table.
  - Floating toggle button to switch seamlessly between raw JSON and table view.
  - Interactive breadcrumbs to drill down into nested objects and arrays.
  - Persistent preference to remember default view mode (Grid or Raw JSON).
  - Automatic theme detection adapting to browser dark mode.
