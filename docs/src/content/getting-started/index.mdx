# Getting Started

This page will guide you through the process of creating your first dynamic data grid component.

For a quick overview about JSOC Grid concept and purpose, refer to the [Introduction](/docs) page.

## Key Terminologies

Throughout this documentation you will notice the below terms being used heavily. 
It will be easier if you understand them before proceeding further.

- **Adapter Package** - Based on your JavaScript framework, you will be using one of the available adapter packages. For list of supported frameworks and their adapter packages, refer to [Adapters page](/docs/adapters).
- **Plugin Package** - Based on your chosen UI component library, you will be using one of the available plugin packages. For list of supported UI components and their plugin packages, refer to [Plugins page](/docs/plugins).

You can gradually learn about core features and terms in the [guides](/docs/guides) section.
