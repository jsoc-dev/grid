# Installation
First of all, you need to have Node.js and NPM (or any other package manager) installed on your machine. If you haven't installed them yet, please follow the instructions on the [Node.js website](https://nodejs.org/) to download and install the latest stable version.

Once you have Node.js and a package manager installed, you can proceed with the installation of the adapter and plugin packages.


## Adapter Package
Run the following command to install the [%%adapter.frameworkName%%](/docs/adapters/%%adapter.id%%) adapter:

```sh npm2yarn
npm install %%adapter.packageName%%
```

Also, install the peer dependencies of the adapter package as listed in the [package.json](https://unpkg.com/%%adapter.packageName%%/package.json) file.


## Plugin Package
Run the following command to install the [%%plugin.name%%](/docs/plugins/%%adapter.id%%-%%plugin.id%%) plugin:

```sh npm2yarn
npm install %%plugin.packageName%%
```

Also, install the peer dependencies of the plugin package as listed in the [package.json](https://unpkg.com/%%plugin.packageName%%/package.json) file.
