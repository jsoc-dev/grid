# Installation

This page covers the installation procedure for the [%%adapter.frameworkName%%](/docs/adapters/%%adapter.id%%) adapter 
and [%%plugin.name%%](/docs/plugins/%%adapter.id%%-%%plugin.id%%) plugin.

## Prerequisites

First of all, you need to have Node.js and NPM (or any other package manager) installed on your machine. If you haven't installed them yet, please follow the instructions on the [Node.js website](https://nodejs.org/) to download and install the latest stable version.

Once you have Node.js and a package manager installed, you can proceed with the installation process below.

## Adapter Package
Run the following command to install the %%adapter.frameworkName%% adapter package:

```sh npm2yarn
npm install %%adapter.packageName%%
```
