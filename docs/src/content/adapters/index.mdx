# Framework Adapters

Framework adapters purpose is to manage the lifecycle of the Grid Store in the particular framework manner. They also provide headless composable components that can be used as slots in the Grid component.

All the [component plugins](./component-plugins.mdx) are built on top of the framework adapters.
If you looking to build a custom plugin for a Grid component, you can use the framework adapter to build it.
All existing component plugins already use the framework adapters to build their functionality.
