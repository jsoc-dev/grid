# Vue Grid Adapter
The official Vue adapter providing idiomatic composables and components for seamless usage of Grid Core API in a Vue application.

<FrameworkIntegration adapterId="vue-grid"/>

## API
Here are some of the key exports provided by the adapter:

- Composables: 
  - [`useGridStoreMemo`](/api/vue-grid/useGridStoreMemo)
  - [`useGridStoreSelector`](/api/vue-grid/useGridStoreSelector)
  
- Components:
  - [`ChildGridToggle`](/api/vue-grid/ChildGridToggle)
  - [`SimpleNavigator`](/api/vue-grid/SimpleNavigator)

You can find the complete API reference at [Vue Adapter API](/api/vue-grid).
