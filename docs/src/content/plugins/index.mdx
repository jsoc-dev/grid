# UI Plugins

**UI Plugins** (or simply **Plugins**) provide a [`ConfigGenerator`](/api/grid-core/ConfigGenerator) that is used when instantiating the [`GridStore`](/api/grid-core/GridStore). 
This generator leverages core utilities (like [`generateColumns`](/api/grid-core/generateColumns)) alongside schema properties (such as [`rows`](/api/grid-core/GridSchema) and 
[`primaryColumnKey`](/api/grid-core/GridSchema)) to directly construct the native configuration required by your chosen UI component.
  
## Available plugins
Plugins are available for various DataGrid and DataTable libraries, organized below by framework.

Click any card to read its documentation, or use the GitHub and npm icons at the top of the card to view its source code and package.
