# Component Plugins

[Framework adapters](./framework-adapters.mdx) alone can't be used to generate configurations for the Grid component. 
For transforming the Grid Schemas to valid grid configurations, you need to use the component plugins.

Component plugins are the plugins that are used to transform the Grid Schemas to valid grid configurations.
